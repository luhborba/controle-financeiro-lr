# Controle Financeiro LR Data Consult

Sistema de controle financeiro pessoal multi-usuário.

## Status do Projeto

🚧 **EM DESENVOLVIMENTO** 🚧

## Sobre

Aplicação web para gestão de:
- Gastos (parcelados ou à vista)
- Cartões de crédito
- Empréstimos
- Proventos (CPF/CNPJ)

## Tecnologias

- Python 3.12
- Django 5.0
- PostgreSQL 16
- Docker
- HTMX + Alpine.js + Tailwind CSS
